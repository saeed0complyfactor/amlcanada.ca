ПО для отчётности в FINTRAC и подача отчётов через API

Ваши отчёты в FINTRAC проверяются, утверждаются и отслеживаются в одном месте.

Наша платформа для отчётности проводит данные о ваших операциях через проверки по правилу 24 часов, валидацию и утверждение, затем подаёт отчёты через API FINTRAC (FINTRAC API report submission), если вы к нему подключены, и сохраняет записи.

Записаться на консультацию Читать далее Расчёт · после звонка для определения объёма

Большая часть работы по отчётности в FINTRAC выполняется до того, как вы нажмёте «Отправить».

Операции хранятся в нескольких системах. Небольшие операции, возможно, придётся суммировать по правилу 24 часов. Данные о лице, проводящем операцию, и о получателе теряются, каждый отчёт нужно проверить перед отправкой, а отклонённый отчёт — исправить и подать повторно. С таблицами и электронной почтой всё это идёт медленно и трудно подтверждается документально.

Наша платформа охватывает пять отчётов, подаваемых в электронном виде: сообщения о подозрительных операциях, отчёты о крупных операциях с наличными, отчёты об электронных переводах денежных средств, отчёты о крупных операциях с виртуальной валютой и отчёты о выплатах казино. Решение о том, о чём сообщать, по-прежнему принимает ваша комплаенс-команда. Платформа выполняет проверки, маршрутизацию и ведение записей вокруг этого решения. Цена подтверждается после звонка для определения объёма.

Как отчёты попадают в FINTRAC

Компания с доступом в интернет должна направлять в FINTRAC сообщения о подозрительных операциях, отчёты о крупных операциях с наличными, отчёты о крупных операциях с виртуальной валютой, отчёты об электронных переводах денежных средств и отчёты о выплатах казино в электронном виде. Отчёты об имуществе включённых в перечень лиц или организаций по-прежнему подаются на бумажной форме. На странице о способах подачи отчётов FINTRAC перечислены две электронные системы отчётности, а также общий процесс одновременной подачи EFTR в FINTRAC и Агентство доходов Канады (Canada Revenue Agency):

  • Система веб-отчётности FINTRAC (FINTRAC Web Reporting System). Вы вводите и подаёте отчёты по одному в браузере. По словам FINTRAC, она рассчитана на компании с небольшим объёмом отчётности.
  • Подача отчётов через API FINTRAC (FINTRAC API report submission). Межсистемное подключение, по которому данные отчётов направляются напрямую в FINTRAC; рассчитано на компании с большими объёмами.

Прежние системы пакетной подачи выводятся из эксплуатации. Переходные периоды FINTRAC для перевода отчётности с большими объёмами на API закончились 6 ноября 2023 г. для LCTR и LVCTR, 3 июля 2024 г. для STR и 22 августа 2024 г. для EFTR и отчётов о выплатах казино (FINTRAC, подача отчётов через API, проверено 15 ноября 2026 г.).

Что включает подача отчётов через API FINTRAC (FINTRAC API report submission)

Для работы с API нужны приложение и секретные ключи, которые ваш технический администратор настраивает через API-портал FINTRAC. Компания, подающая отчёты в больших объёмах и ещё не имеющая доступа к API, обращается в FINTRAC по адресу F2R@fintrac-canafe.gc.ca.

FINTRAC предлагает две группы конечных точек (endpoints): одну для отдельных отчётов, другую для пакетной подачи, и каждая позволяет создать, изменить или удалить поданный отчёт. Отдельный отчёт может содержать до 500 операций (25 МБ). Пакетный файл может содержать до 5 000 отчётов и до 5 000 операций в каждом отчёте в пределах 300 МБ. FINTRAC публикует JSON-схемы и правила валидации для каждого типа отчёта.

Наша платформа формирует данные отчётов в формате, который ожидает API FINTRAC, подаёт утверждённые отчёты по отдельности или пакетом и фиксирует ответ FINTRAC по каждому отчёту. Если ваша компания ещё не подключена к API, мы поможем с подключением. До тех пор платформа готовит прошедшие валидацию и утверждённые данные отчётов для подачи через ваш текущий канал FINTRAC и фиксирует статус по отчёту.

Проверки по правилу 24 часов

Для крупных операций с наличными и с виртуальной валютой правило 24 часов FINTRAC означает, что две или более операции на любую сумму, в совокупности составляющие 10 000 CAD или более в пределах 24 часов, отражаются в отчёте вместе, если вы знаете, что они проведены одним и тем же лицом или организацией либо от их имени или в пользу одного и того же получателя. Для электронных переводов денежных средств и выплат казино действуют собственные правила суммирования. FINTRAC ожидает, что правило будет применяться во всех ваших точках, а вручную это сложно делать по всем филиалам, агентам и платёжным каналам.

Правило работает не одинаково для всех отчётов. Какие операции суммируются, зависит от типа отчёта, времени, того, кто их провёл, третьих лиц и получателей. Платформа применяет настраиваемые проверки для каждого типа отчёта и показывает операции, которые она сгруппировала. Ваша команда подтверждает, требуется ли отчёт.

Валидация перед подачей отчёта

Система веб-отчётности FINTRAC (FINTRAC Web Reporting System), согласно её руководству, показывает два вида сообщений валидации. Сообщение «отклонено» означает, что отсутствует обязательная информация, и отчёт нельзя подать, пока её не добавят. Предупреждение означает, что информация с пометкой «обязательно, если применимо» отсутствует или неполна. Предупреждение не препятствует подаче, но если эта информация есть в ваших записях, вы обязаны её указать.

Платформа выполняет проверки до того, как отчёт поступит на утверждение. Она проверяет:

  • обязательные поля и поля «обязательно, если применимо»;
  • форматы, коды и условные поля;
  • отсутствие информации о лице, проводящем операцию, или о получателе, а также поля о третьих лицах в отчётах о выплатах казино;
  • повторяющиеся референс-номера отчётов и отсутствующие связи между операциями;
  • даты и суммы, которые не сходятся.

Блокирующие ошибки показываются отдельно от предупреждений, поэтому ваша команда сначала устраняет то, что помешало бы подаче. Валидация не гарантирует, что FINTRAC примет отчёт.

Проверка и утверждение

Проверка по принципу четырёх глаз (maker-checker) настраивается. Исполнитель готовит отчёт и проводит его валидацию, а контролёр его утверждает. Контролёры могут оставлять комментарии прямо в отчёте и возвращать его на исправление, а каждое действие фиксируется с отметкой времени, поэтому вы можете показать, кто и когда подготовил, проверил, утвердил и подал каждый отчёт. Напоминания отмечают отчёты, срок подачи которых приближается.

Сообщения о подозрительных операциях требуют суждения, которое программное обеспечение дать не может. Платформа предоставляет структурированные поля для описательной части и направляет отчёт на утверждение, но установление разумных оснований для подозрения, составление описательной части и решение о подаче остаются за вашим комплаенс-офицером. Использование платформы не переносит вашу юридическую ответственность за отчётность.

После подачи

Поданный отчёт может вернуться с предупреждениями или быть отклонён. Платформа фиксирует подтверждение получения и номер подтверждения от FINTRAC, сохраняет отправленные данные JSON, назначает исправления сотруднику и связывает каждую исправленную версию с исходной, так что история отчёта читается как единая запись. Изменять или удалять поданные отчёты можно в рамках того же рабочего процесса.

Поданные отчёты хранятся в архиве, который можно скачать в формате PDF или CSV. Параметры хранения подтверждаются письменно на этапе определения объёма. Это даёт тому, кто проводит вашу проверку эффективности, и проверяющим FINTRAC запись с отметками времени о проверке и утверждении каждого отчёта, об отправленных данных JSON и об ответе FINTRAC.

Как мы всё настраиваем

  1. Звонок для определения объёма. Ваши типы отчётов, источники данных и то, как вы подаёте отчёты сейчас.
  2. Анализ данных. Мы проверяем, какие поля есть в ваших системах и каких данных для отчётности не хватает.
  3. Настройка. Специалист по комплаенсу настраивает ваши типы отчётов, пороги, правила суммирования, сопоставления полей, роли пользователей и маршруты утверждения.
  4. Тестирование. Мы тестируем на примерах и прошлых операциях в изолированной тестовой среде (песочнице), отдельно от реальной подачи в FINTRAC.
  5. Подключение к API. Если это применимо, мы помогаем вам пройти подключение к API FINTRAC.
  6. Запуск. Утверждённые рабочие процессы переводятся в рабочую среду.

Стандартных сроков внедрения нет. Меры безопасности, место хостинга и локализация данных подтверждаются письменно для каждого клиента на этапе определения объёма. Если вы предпочитаете не вести отчётность самостоятельно, наша услуга внешнего комплаенс-офицера включает отчётность в FINTRAC.

ПО для отчётности в FINTRAC: вопросы

Остались вопросы? Запишитесь на консультацию или напишите на info@amlcanada.ca.

Что такое ПО для отчётности в FINTRAC?

Программное обеспечение, которое помогает отчитывающейся организации готовить, проверять, утверждать, подавать и отслеживать отчёты, которые она обязана направлять в FINTRAC, например STR, LCTR, EFTR и LVCTR. Наше ПО также применяет проверки по правилу 24 часов и хранит полную историю каждого отчёта.

Какие отчёты FINTRAC поддерживает платформа?

Сообщения о подозрительных операциях, отчёты о крупных операциях с наличными, отчёты об электронных переводах денежных средств, отчёты о крупных операциях с виртуальной валютой и отчёты о выплатах казино. Отчёты об имуществе включённых в перечень лиц или организаций подаются на бумаге, поэтому они не охвачены.

Подаёт ли платформа отчёты в FINTRAC напрямую?

Да, через API FINTRAC (FINTRAC API report submission), как только ваша компания будет подключена. До тех пор она готовит прошедшие валидацию и утверждённые данные отчётов для вашего текущего канала подачи в FINTRAC.

Решает ли ПО, подавать ли STR?

Нет. Оно структурирует подготовку и утверждение, но разумные основания для подозрения, описательная часть и решение о подаче остаются за вашей комплаенс-командой.

Можем ли мы импортировать свои файлы с операциями?

Да. Основной способ импорта — структурированные файлы, например выгрузки в CSV, а повторно используемые сопоставления связывают ваши поля с полями отчётов FINTRAC. Другие источники подтверждаются на этапе определения объёма.

Сколько это стоит?

Цена подтверждается после звонка для определения объёма.

Где размещаются наши данные?

Место хостинга, локализация данных и меры безопасности подтверждаются письменно для каждого клиента на этапе определения объёма.
